A ferramenta gratuita do Raspberry Pi que você deveria usar para acesso remoto

Conheça o Raspberry Pi Connect, um programa oficial que elimina a necessidade de encaminhamento de portas para acessar seu dispositivo remotamente com segurança.

O acesso remoto a um Raspberry Pi é um recurso indispensável para projetos domésticos quando não é possível alcançar o dispositivo fisicamente. Antigamente, conectar-se à placa significava configurar um serviço VNC ou túneis SSH, métodos que exigem o encaminhamento de portas. Isso pode representar uma dor de cabeça para iniciantes e um risco potencial de segurança para determinados projetos. Felizmente, existe uma alternativa melhor para acessar o Raspberry Pi remotamente sem precisar lidar com portas.

O que é o Raspberry Pi Connect?

O Raspberry Pi Connect é um programa criado pela própria fundação Raspberry Pi que permite a comunicação com a unidade pela internet, mesmo estando fora da rede local. Ele é conveniente, dispensa o encaminhamento de portas e funciona de forma automática se o dispositivo estiver rodando o sistema operacional Bookworm ou versões posteriores. Dispositivos mais antigos contam com opções limitadas, mas, desde que rodem o Raspberry Pi OS ou sua variante Lite, a configuração pode ser feita rapidamente executando alguns comandos em um terminal SSH.

Como a ferramenta funciona

O programa utiliza a tecnologia WebRTC, que estabelece uma conexão ponto a ponto entre dois navegadores web através de um túnel seguro. A ferramenta não requer nenhum software de terceiros na unidade e sua natureza segura permite contornar firewalls rígidos e NATs restritos. Como opera pela internet, é necessário ter acesso à rede e possuir uma conta no Raspberry Pi Connect.

A ferramenta oferece duas funcionalidades principais para os usuários:

  • Compartilhamento de tela: transforma o navegador em uma área de trabalho remota para o dispositivo, rodando por meio de uma sessão Wayland que consome recursos do Pi e exige uma sessão de desktop ativa.
  • Shell remoto: atua como um terminal SSH executado diretamente no navegador, sendo ideal para monitorar o sistema ou rodar comandos à distância sem precisar de uma interface gráfica.

Como utilizar o programa na prática

Usar o Raspberry Pi Connect é um processo simples. Você precisará de duas coisas principais: o pacote instalado na unidade e uma conexão com a internet. O utilitário é disponibilizado em duas versões:

  • Pacote completo: inclui compatibilidade com o compartilhamento de tela para unidades conectadas a um monitor.
  • Pacote lite: voltado exclusivamente para o acesso remoto via terminal.

Para realizar a instalação, inicie uma sessão SSH com a unidade e execute os comandos adequados no terminal. Para o pacote completo, digite o comando para instalação padrão. Para o pacote leve, utilize a versão lite. Após a conclusão da instalação de qualquer uma das opções, basta digitar o comando para habilitar o acesso à internet.

Com o serviço ativado, acesse o site oficial da ferramenta e faça login na sua conta do Raspberry Pi, ou crie uma nova caso ainda não possua. Depois de entrar, será necessário vincular a unidade à conta seguindo as instruções disponíveis na seção de primeiros passos do site oficial. Por fim, entre na sua conta, selecione o botão de conexão e escolha a opção desejada para gerenciar o dispositivo.

Por que isso importa

A ferramenta elimina barreiras técnicas complexas e riscos de segurança associados ao encaminhamento de portas, facilitando o uso de dispositivos Raspberry Pi por iniciantes e entusiastas.

O que pode acontecer no futuro

Se essa tendência continuar, ferramentas nativas focadas em segurança e facilidade de uso podem se tornar o padrão para o gerenciamento de dispositivos IoT e computadores de placa única, reduzindo a dependência de configurações manuais avançadas.
