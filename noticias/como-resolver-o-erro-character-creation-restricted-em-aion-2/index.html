Como resolver o erro 'Character creation restricted' em Aion 2

Jogadores de Aion 2 têm enfrentado dificuldades para iniciar o jogo devido a um erro na criação de personagens. Confira os métodos para contornar esse problema técnico.

O problema da criação de personagens em Aion 2

Aion 2, o aguardado título que acaba de ser lançado, tem apresentado um obstáculo frustrante para muitos jogadores logo no início da jornada: o erro "Character creation restricted". Esse problema impede que o usuário finalize a criação de seu personagem, impossibilitando o acesso ao jogo. A falha parece estar relacionada a uma sensibilidade do software em relação às configurações do sistema operacional, algo que pode ter passado despercebido durante a fase de testes de qualidade.

Método 1: Ajuste automático de data e hora

A primeira e mais simples solução envolve verificar as configurações de tempo do seu computador. O jogo exige que o relógio do sistema esteja sincronizado corretamente para validar a conexão com os servidores.

  • Feche o jogo completamente antes de realizar as alterações.
  • Acesse o menu de configurações de "Data e Hora" do Windows (clique com o botão direito sobre o relógio na barra de tarefas e selecione "Ajustar data e hora").
  • Certifique-se de que as opções "Definir fuso horário automaticamente" e "Definir horário automaticamente" estejam ativadas.
  • Após ativar essas opções, reinicie o jogo e verifique se o erro persiste.

Método 2: Alteração das configurações de DNS

Caso o ajuste de horário não resolva, o problema pode estar relacionado à resolução de rede. Alterar os servidores DNS pode contornar bloqueios ou falhas de comunicação entre o seu provedor e os servidores do jogo.

  • Abra o Painel de Controle e navegue até a "Central de Rede e Compartilhamento".
  • Clique em "Alterar as configurações do adaptador".
  • Clique duas vezes na sua conexão de rede ativa e selecione "Propriedades".
  • Localize e selecione "Protocolo IP Versão 4 (TCP/IPv4)" e clique em "Propriedades".
  • Mantenha a opção de IP em "Obter um endereço IP automaticamente".
  • Altere a configuração de DNS para "Usar os seguintes endereços de servidor DNS" e insira os endereços do Google:
  • Servidor DNS preferencial: 8.8.8.8
  • Servidor DNS alternativo: 8.8.4.4
  • Clique em OK e tente iniciar o jogo novamente.

Método 3: Uso de VPN

Se as etapas anteriores não surtirem efeito, é possível que a sua conta ou o seu endereço IP tenham sido sinalizados ou bloqueados pelo sistema do jogo. Nesse cenário, a solução é mais drástica.

  • Utilize uma VPN configurada para a região de Taiwan.
  • Crie uma nova conta de jogo especificamente para a região de Taiwan.

Esta é considerada a última alternativa para contornar restrições de conta ou IP. É importante ressaltar que a alteração de configurações de rede deve ser feita apenas por usuários que se sintam confortáveis em reverter as mudanças caso algo não funcione como esperado.

Por que isso importa

O erro impede o acesso direto ao conteúdo do jogo, frustrando novos jogadores logo na etapa inicial de criação de personagem. As soluções apresentadas são essenciais para que a base de usuários consiga contornar falhas de configuração do sistema ou bloqueios regionais que impedem a jogabilidade.

O que pode acontecer no futuro

Se essa tendência de erros de configuração continuar, é possível que a desenvolvedora lance patches de correção para tornar o cliente do jogo menos sensível às configurações de rede e de horário do Windows. Também é possível que, com o tempo, novas ferramentas de diagnóstico sejam disponibilizadas para evitar que jogadores precisem recorrer a soluções externas como VPNs.
