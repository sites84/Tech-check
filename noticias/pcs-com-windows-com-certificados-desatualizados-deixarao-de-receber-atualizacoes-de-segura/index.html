PCs com Windows com certificados desatualizados deixarão de receber atualizações de segurança

A Microsoft alertou que computadores rodando versões mais antigas do Windows com certificados desatualizados nos serviços de atualização vão parar de receber os pacotes mensais de segurança se não passarem pela substituição necessária.

A Microsoft emitiu um aviso importante sobre a continuidade das atualizações de segurança em computadores que rodam o sistema operacional Windows. Segundo a empresa, os certificados digitais utilizados pelos serviços do Windows Update possuem uma data de validade pré-estabelecida e precisam ser substituídos periodicamente para que os dispositivos continuem aptos a receber os pacotes mensais de correção e melhorias. ## A situação das diferentes versões do Windows A exigência de renovação afeta diretamente a forma como o sistema gerencia a segurança das conexões com os servidores da empresa. Enquanto os computadores que rodam o Windows 11 versão 25H2 e edições posteriores já contam com os certificados mais recentes integrados de fábrica, o cenário é diferente para os usuários que utilizam versões anteriores do sistema operacional. Esses dispositivos mais antigos que mantiveram certificados desatualizados enfrentarão barreiras técnicas para se comunicarem com o serviço de atualizações, interrompendo o ciclo de recebimento de patches essenciais de segurança. ## O que os usuários devem fazer Para garantir que os equipamentos permaneçam protegidos contra vulnerabilidades recém-descobertas e continuem recebendo o suporte mensal da desenvolvedora, é fundamental tomar medidas preventivas. Entre as ações recomendadas estão - Verificar se o sistema operacional está configurado para receber as atualizações automáticas mais recentes. - Acompanhar os comunicados oficiais da Microsoft sobre procedimentos de remediação para certificados expirados. - Considerar a atualização para versões mais recentes do Windows, como o Windows 11 25H2, que já trazem os certificados válidos nativamente.

Por que isso importa

Esta questão é relevante porque afeta diretamente a segurança digital dos usuários, já que computadores que deixam de receber atualizações mensais ficam mais vulneráveis a falhas de segurança e ameaças virtuais.

O que pode acontecer no futuro

Se essa tendência continuar, é possível que mais usuários de versões legadas do Windows precisem migrar obrigatoriamente para edições mais recentes do sistema operacional para manterem seus dispositivos protegidos e funcionais.
