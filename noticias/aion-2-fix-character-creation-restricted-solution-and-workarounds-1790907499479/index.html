Como resolver o erro 'Character creation restricted' em Aion 2

Jogadores de Aion 2 têm enfrentado dificuldades para iniciar a jornada devido a uma restrição na criação de personagens. Confira os métodos para contornar esse problema técnico.

O problema da restrição em Aion 2

Aion 2 chegou ao mercado, mas nem todos os jogadores estão conseguindo dar os primeiros passos. Um erro específico, identificado como 'Character creation restricted' (criação de personagem restrita), tem impedido que usuários finalizem a personalização de seus avatares. O problema parece estar relacionado a uma sensibilidade do jogo em relação às configurações do sistema operacional, algo que pode ter passado despercebido durante a fase de testes de qualidade.

Para ajudar a comunidade a contornar essa falha, compilamos três métodos principais que podem restaurar o acesso ao jogo.

Método 1: Ajuste automático de data e hora

Esta é a solução mais simples e deve ser a primeira a ser tentada. O jogo exige que o relógio do sistema esteja sincronizado corretamente para validar a conexão com os servidores.

  • Feche o jogo completamente.
  • Acesse as configurações de 'Data e Hora' do Windows (clique com o botão direito sobre o relógio na barra de tarefas e selecione 'Ajustar data e hora').
  • Certifique-se de que as opções 'Definir fuso horário automaticamente' e 'Definir horário automaticamente' estejam ativadas.
  • Após realizar a alteração, reinicie o jogo e verifique se o problema persiste.

Método 2: Alteração das configurações de DNS

Caso o ajuste de horário não funcione, o problema pode estar relacionado à resolução de rede. A alteração dos servidores DNS pode contornar bloqueios ou falhas de comunicação com os servidores do jogo.

  • Abra o Painel de Controle e navegue até a 'Central de Rede e Compartilhamento'.
  • Clique em 'Alterar as configurações do adaptador'.
  • Clique duas vezes na sua conexão de rede ativa e selecione 'Propriedades'.
  • Localize e selecione 'Protocolo IP Versão 4 (TCP/IPv4)' e clique em 'Propriedades'.
  • Mantenha a opção de obter um endereço IP automaticamente, mas altere a parte inferior para 'Usar os seguintes endereços de servidor DNS'.
  • Insira os seguintes valores: Servidor DNS preferencial: 8.8.8.8 e Servidor DNS alternativo: 8.8.4.4.
  • Clique em OK e tente iniciar o jogo novamente.

Método 3: Uso de VPN

Se as etapas anteriores não surtirem efeito, é possível que a sua conta ou o seu endereço IP tenham sido sinalizados ou bloqueados pelo sistema do jogo. Neste cenário, a solução é mais drástica.

  • Utilize um serviço de VPN configurado para a região de Taiwan.
  • Crie uma nova conta de jogo especificamente para a região de Taiwan.

Esta última opção é considerada o recurso final para jogadores que não conseguiram resolver o erro através das configurações locais de sistema ou rede.

Por que isso importa

O erro impede que novos jogadores iniciem a experiência em Aion 2, tornando a resolução desses problemas técnicos essencial para a acessibilidade do título. As soluções propostas abordam desde falhas simples de sincronização de sistema até restrições de rede mais complexas que podem afetar a jogabilidade.

O que pode acontecer no futuro

Se essa tendência de restrições continuar, é possível que a desenvolvedora lance atualizações de software para tornar o jogo menos sensível às configurações de rede e de horário dos usuários. Também é possível que, se o problema for generalizado, a empresa implemente correções diretas nos servidores para evitar que contas legítimas sejam sinalizadas erroneamente.

São cenários possíveis, não previsões garantidas.
