LINE Games lança a Demo 2.0 de CODE EXIT para PC

A LINE Games disponibilizou em 23 de outubro a Demo 2.0 do jogo de terror cooperativo e sci-fi CODE EXIT, desenvolvido pelo Phase 8 Studio para PC nas plataformas Steam e Epic Games Store.

Assistir no YouTube

Uma nova versão de testes para os jogadores de PC

A LINE Games anunciou oficialmente o lançamento da Demo 2.0 de CODE EXIT, um jogo de terror e ficção científica com foco cooperativo desenvolvido pelo Phase 8 Studio. A nova versão de testes ficou disponível para o público a partir do dia 23 de outubro, ampliando o acesso dos entusiastas do gênero ao título.

Plataformas e melhorias baseadas na comunidade

Os interessados em conferir a nova versão podem encontrar a demonstração em duas das principais vitrines digitais da atualidade para computadores: o Steam e a Epic Games Store. Segundo as informações divulgadas, esta atualização da demonstração foi construída levando diretamente em conta o feedback coletado junto aos jogadores durante um teste anterior realizado exclusivamente na plataforma da Valve.

Com base nessas opiniões da comunidade, a desenvolvedora Phase 8 Studio focou seus esforços em aprimorar aspectos fundamentais da experiência de jogo, incluindo melhorias significativas nos comandos e em elementos essenciais do gameplay para garantir uma imersão ainda maior aos grupos de jogadores que se arriscam no universo de terror e sci-fi de CODE EXIT.

Por que isso importa

A notícia é relevante por demonstrar como estúdios de desenvolvimento utilizam o feedback direto de testes anteriores com jogadores para aprimorar mecânicas de controle e jogabilidade em títulos em desenvolvimento, além de ampliar o acesso multiplataforma em lojas digitais importantes para PC.

O que pode acontecer no futuro

Se essa tendência continuar, a recepção da Demo 2.0 pode orientar os próximos passos do Phase 8 Studio no polimento final do jogo, e é possível que novos testes públicos sejam realizados antes do lançamento da versão definitiva.
