Como ativar o modo escuro no Google Docs para web usando alternativas simples

O Google Docs oferece suporte ao modo escuro em seus aplicativos móveis, mas o recurso continua ausente na versão para navegadores web. Felizmente, existem alternativas oficiais e extensões de terceiros que resolvem o problema.

O Google Docs é uma ferramenta extremamente conveniente e que recebe atualizações e suporte constantes. Recentemente, a empresa tem lançado cada vez mais recursos novos para o processador de texto, trazendo ferramentas de criação de conteúdo impulsionadas pelo Gemini para o Docs, além de uma série de outras atualizações de inteligência artificial. No entanto, há um recurso muito solicitado que historicamente tem escapado e continua ausente do repertório do Google Docs na web.

O contraste entre as versões mobile e web

O processador de texto do Google tem muitas vantagens, como a forma de fazer a ponte perfeitamente entre suas diferentes plataformas de hospedagem, ao contrário do Microsoft Word, que é bem mais pesado no celular. Curiosamente, um dos recursos que faltam no Docs expõe uma divisão entre as versões do produto. Essa funcionalidade ausente é o modo escuro, que está presente no celular, mas continua faltando na versão web. O modo escuro é uma omissão evidente no site do Google Docs, por isso é uma sorte que existam maneiras de contornar essa deficiência tanto dentro quanto fora da alçada direta do Google.

As rotas oficiais para o modo escuro no Docs

O Google começou a disponibilizar o modo escuro para o Docs em dispositivos móveis no ano de 2020, primeiro no Android e posteriormente na versão da Apple para o aplicativo. Em qualquer uma das versões, você pode encontrar o modo escuro seguindo o caminho de Menu, depois Configurações e Tema, ou Escolher Tema caso esteja usando o Android. A partir daí, é possível selecionar entre Escuro, Claro ou Padrão do Sistema.

Infelizmente, você não encontra essa variedade de opções de brilho no próprio site do Google Docs. A empresa não listou um motivo oficial para esse favorecimento ao lado móvel de suas ofertas, mas ao menos ofereceu uma única alternativa interna através dos recursos experimentais do navegador Chrome. Ao pesquisar chrome://flags no Chrome, você consegue acessar essas ferramentas e procurar por Auto Dark Mode for Web Contents. Contudo, vale o aviso: esses recursos são experimentais e podem comprometer dados do navegador e a segurança do dispositivo, portanto há riscos ao ativar essa função.

O uso de extensões de navegador

Por sorte, existem maneiras de acessar o modo escuro sem depender de chaves experimentais arriscadas. Você não precisa esperar pelo futuro do Google Docs para usar extensões de navegador hoje, o que inclui a extensão Google Docs Dark Mode disponível na Chrome Web Store, ou uma alternativa para o seu navegador de preferência, como o DocsAfterDark no Firefox. Não é a única extensão que cobre essa área, mas representa uma excelente escolha e funciona com facilidade.

Uma vez instalada de forma gratuita, essa extensão de navegador ativa o modo escuro automaticamente no Google Docs. Se você quiser alterar as configurações do modo escuro ou desativar a extensão completamente, basta clicar no ícone de Extensões localizado próximo à barra de pesquisa, que possui o formato de uma peça de quebra-cabeça no canto superior direito da tela. Por lá, é possível realizar as seguintes ações:

  • Desativar o modo escuro quando necessário
  • Selecionar um tema de cores específico
  • Ajustar individualmente configurações de sépia, contraste, escala de cinza e brilho

Além de todas essas vantagens de personalização, a extensão desativa o modo escuro automaticamente para impressões, poupando o usuário de ter que ligar e desligar o recurso toda vez que precisar imprimir um documento.

Por que isso importa

A ausência de um recurso básico como o modo escuro na versão web do Google Docs afeta a experiência de usuários que passam muitas horas diante de telas de computadores, tornando alternativas de terceiros e ajustes experimentais necessários para o conforto visual.

O que pode acontecer no futuro

Se essa tendência continuar, é possível que o Google finalmente decida implementar o modo escuro de forma nativa na versão web do Google Docs no futuro, eliminando a dependência de extensões externas ou bandeiras experimentais do navegador.
