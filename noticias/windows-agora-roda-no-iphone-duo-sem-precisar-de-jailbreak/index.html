Windows agora roda no iPhone Duo sem precisar de jailbreak

Um novo projeto chamado WindowsiOS criado por Ammaar Reshi permite rodar uma versão comercial do Windows 11 em um dispositivo iOS sem a necessidade de desbloqueio do sistema.

O projeto WindowsiOS surpreende entusiastas

Um desenvolvedor conseguiu fazer o sistema operacional Windows rodar em um dispositivo iOS sem que seja necessário realizar o processo de jailbreak. O projeto inovador recebeu o nome de WindowsiOS e chama a atenção da comunidade de tecnologia pela audácia técnica envolvida.

A iniciativa partiu de Ammaar Reshi, profissional que atua como líder de produto e design no Google AI Studio. Ele utilizou sua conta na rede social X para publicar uma demonstração em vídeo do projeto e também disponibilizou todo o código-fonte publicamente no GitHub para quem quiser conferir os detalhes.

Demonstração prática do sistema operacional

O vídeo demonstrativo compartilhado por Reshi exibe de maneira surpreendente uma cópia comercial do Windows 11 na versão 24H2 em pleno funcionamento.

Entre as atividades exibidas na demonstração, o sistema consegue executar softwares conhecidos dos usuários de computadores convencionais. Foram mostrados em execução o navegador Microsoft Edge e a ferramenta Google Antigravity.

Impacto para a comunidade

A disponibilização do código-fonte no GitHub permite que outros desenvolvedores e entusiastas examinem a arquitetura da solução e entendam como foi possível contornar as restrições tradicionais do ecossistema móvel da Apple.

Embora projetos desse tipo costumem surgir com frequência no universo da engenharia reversa e de experimentos com sistemas, a ausência de jailbreak adiciona um nível considerável de interesse prático e técnico para a comunidade.

Por que isso importa

A notícia importa porque demonstra os limites atuais da engenharia de software e da experimentação com sistemas operacionais, mostrando que é possível executar softwares complexos de desktop como o Windows 11 em ambientes móveis sem modificações profundas no sistema operacional de fábrica.

O que pode acontecer no futuro

Se essa tendência continuar, é possível que mais desenvolvedores explorem métodos semelhantes para rodar ambientes de desktop em smartphones, e projetos de código aberto como o WindowsiOS podem inspirar novas abordagens para a compatibilidade de sistemas no futuro.
