Minecraft receberá controles de mouse no Joy-Con em futura atualização no Switch 2

O popular jogo Minecraft ganhará suporte a controles de mouse utilizando os Joy-Con do Nintendo Switch 2 em uma futura atualização. A novidade já está disponível para testes em uma versão beta fechada.

Novidades no horizonte para o Minecraft no Switch 2

Quem tem acompanhado as análises especializadas da versão de Minecraft para o Nintendo Switch 2 já percebeu a ausência de um recurso bastante aguardado: o modo de mouse. A boa notícia é que a desenvolvedora já está trabalhando ativamente em uma atualização futura para introduzir os controles de mouse do novo Joy-Con diretamente no jogo.

Atualmente, esses novos recursos de controle já podem ser testados por jogadores que possuem acesso à versão beta fechada do título. Embora ainda não exista uma data de lançamento oficial confirmada para a disponibilização pública desse recurso para todos os jogadores, a expectativa é que a novidade chegue em algum momento nos próximos meses.

Como funcionarão os controles de mouse

A implementação trará diversas opções de personalização e flexibilidade para os jogadores aproveitarem o sandbox da Mojang de uma maneira diferente. Entre as principais características reveladas para o sistema de controle com os novos Joy-Con, destacam-se:

  • Uso de controles de mouse com o Joy-Con esquerdo ou com o Joy-Con direito.
  • Ajustes de configurações personalizadas, incluindo a sensibilidade do cursor e da câmera.
  • Posicionamento de blocos utilizando o botão ZL.
  • Ações de quebrar e selecionar blocos utilizando o botão ZR.
  • Ajustes adicionais no layout dos botões diretamente nas configurações do jogo.

Atualizações e promoções para proprietários

Além das novidades sobre os controles de mouse, vale lembrar que os jogadores que já possuem a versão digital de Minecraft para o Nintendo Switch original têm direito a uma atualização gratuita para a versão de Switch 2 até o final de janeiro de 2027. Para os proprietários de cópias físicas no console anterior, também há opções de descontos vantajosos na aquisição do pacote de atualização 'Ultimate Collection' para a nova plataforma.

Por que isso importa

A notícia é relevante porque aborda a adição de um recurso de jogabilidade muito aguardado e ausente na versão inicial do Minecraft para o Nintendo Switch 2, oferecendo novas opções de controle e customização para a base de fãs do jogo.

O que pode acontecer no futuro

Se essa tendência continuar, é possível que mais jogos do Nintendo Switch 2 adotem os controles de mouse dos novos Joy-Con para melhorar a precisão em gêneros como estratégia e construção. Novos detalhes sobre a data de lançamento oficial podem surgir assim que a fase de testes beta for concluída.
