O que é um endereço IP?

RESUMO

Entenda o que é um endereço IP, a diferença entre IPv4 e IPv6, endereços públicos e privados e como os pacotes são encaminhados.

Quando um dispositivo participa de uma rede IP, ele precisa ter um endereço que possa ser usado para identificar a origem e o destino dos pacotes. Em uma rede doméstica, por exemplo, o celular pode receber um endereço privado do roteador enquanto o roteador utiliza um endereço público para se comunicar com a internet.

IPv4 normalmente é escrito em quatro números separados por pontos, como 192.168.1.20. Esses endereços possuem 32 bits e, por isso, o número de combinações disponíveis é limitado. A expansão da internet e a quantidade crescente de dispositivos tornaram esse espaço insuficiente para atender todas as necessidades diretamente.

Para prolongar a vida útil do IPv4, tecnologias como NAT permitem que vários dispositivos de uma rede privada compartilhem um endereço público. Isso é comum em residências, mas não elimina a necessidade de IPv6, que possui um espaço de endereçamento muito maior.

IPv6 utiliza 128 bits e é representado em grupos hexadecimais. A quantidade de endereços possível é gigantesca, permitindo uma arquitetura muito mais ampla. A adoção, porém, ocorre gradualmente porque redes, equipamentos e serviços precisam oferecer suporte ao protocolo.

Ter um endereço IP não significa necessariamente que o dispositivo esteja diretamente exposto à internet. Endereços privados são utilizados dentro de redes locais e normalmente não são roteados diretamente pela internet pública. Firewalls, NAT e outras camadas também podem controlar o acesso.

Um endereço IP também não é uma identidade pessoal perfeita. Ele pode mudar, ser compartilhado por vários usuários ou representar a conexão de uma rede inteira. A localização aproximada obtida a partir de um IP também pode ser imprecisa.

Quando você abre um site, seu dispositivo coloca informações de origem e destino nos pacotes IP. Os roteadores usam esses dados para encaminhar os pacotes pela rede. O endereço IP funciona, portanto, como uma parte fundamental do sistema de entrega de dados.

IP é apenas uma camada da comunicação. Aplicações precisam de outros protocolos para estabelecer conexões, proteger dados, transportar informações e interpretar o conteúdo recebido. É essa combinação de camadas que permite que serviços tão diferentes funcionem sobre a mesma infraestrutura de rede.
