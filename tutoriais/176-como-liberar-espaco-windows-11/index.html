Como liberar espaço no Windows 11 sem apagar seus arquivos importantes

Use as ferramentas nativas do Windows para encontrar arquivos temporários, aplicativos pesados e arquivos pessoais que podem ser removidos ou movidos.

Tempo de leitura: 8 min

PASSO 1 — Veja quanto espaço existe

Abra Configurações > Sistema > Armazenamento. O Windows mostra quanto espaço está sendo usado e quais categorias ocupam a unidade.

PASSO 2 — Abra os arquivos temporários

Entre em Arquivos temporários. O Windows apresenta categorias que podem ser removidas. Leia cada item antes de marcar a caixa, porque algumas categorias podem conter arquivos que você ainda pretende recuperar.

PASSO 3 — Use o Sensor de Armazenamento

Ative o Sensor de Armazenamento para que o Windows faça limpezas automáticas de arquivos desnecessários conforme as regras configuradas. Ele é especialmente útil para manutenção contínua.

PASSO 4 — Remova aplicativos que você não usa

Em Aplicativos instalados, organize a lista por tamanho. Desinstale programas que você reconhece e sabe que não utiliza mais. Não remova componentes do sistema ou drivers apenas porque ocupam espaço.

PASSO 5 — Procure arquivos pessoais grandes

Abra o Explorador de Arquivos e confira Downloads, Vídeos, Imagens e Documentos. Ordene por tamanho para localizar rapidamente os maiores arquivos. Mova para um HD externo ou exclua apenas aquilo que não precisa.

PASSO 6 — Esvazie a Lixeira

Arquivos enviados para a Lixeira continuam ocupando espaço. Depois de conferir o conteúdo, esvazie-a para recuperar o armazenamento.

IMPORTANTE

Use primeiro as ferramentas nativas do Windows e revise cada categoria antes de excluir. A Microsoft recomenda verificar o que será removido e lembra que liberar espaço também pode ajudar quando há problemas para instalar atualizações.
